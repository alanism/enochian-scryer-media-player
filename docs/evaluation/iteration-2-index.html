Usability and evidence

Apple’s desktop usability guidance informed familiar keyboard commands, file navigation, cancellation, information density and user-controlled fullscreen. Linux/VLC conventions and Enochian aesthetics remain. The principle-to-criterion map uses the existing rubric weights.

27 native observations · Browser journeys and limits · Actual selection/piece evidence · Build and installed-upgrade checks · Reproducible gate result

Native Open/cancel began on Omarchy’s XWayland desktop. The subsequent real VLC workflow checks used approved X11 input on a private authenticated Xvfb display, separate configuration, generated media and a silent Pulse sink. API readbacks verified actual state; API-only setup is labeled. Save used VLC’s own native exporter. Screenshots below are actual windows/browser frames.

Checked: single/multiple Open and append; transport and boundary seeks; rotary/mute; audio/subtitles/speed/EQ; fullscreen/Escape; queue selection/removal/sort/drag; named Unicode XSPF Save/Cancel/reopen and missing-file recovery; torrent file/link review, destination, inclusion, completion truth, keep-files removal; real completed/partial/per-file handoff; Show file and missing feedback; settings failure/cancel and isolated restart.

Published v0.4.1 adds a fresh-profile native EQ DSP check: settings readbacks alone were insufficient. Missing bands now initialize flat without replacing saved gains; the first native enable loads the actual filter, and disable removes it.

Limits retained in the scores

Native Qt dialogs differ from the custom surfaces; primary Open retains an Open Media/Add stage while Ctrl+O uses a direct picker. Some preserved gray labels are small. Duplicate basenames need advanced location inspection. Rate limits reset on engine restart. Bitmap controls lack full native accessibility semantics. Automatic corrupt-media feedback was inconsistent in one instance; retry worked. No physical speaker, high-DPI/multi-monitor, screen-reader or separate reduced-motion session was tested. File-manager fallback is regression-tested with a mocked failure.
