# Jayse Hansen: five-level, 20-criterion evaluation

Project-specific adaptation of a supplied reference; not an official rubric, endorsement or review by the named designer.

Supplied reference: **jayse_hansen_design_hero.md**. SHA-256: 7a5e824ca8f48e01d8aee545a916d47e363ec9d20bcf327a801b9ffc340d605a.

Apply cinematic/slide advice to real desktop utility, clarity, material fidelity, hierarchy and motion. Existing user elements and usability requirements take priority over film-specific prescriptions. No fictional data or decorative motion is required for points.

## Five levels

| Points | Anchor |
| --- | --- |
| 1 | Absent or contradicts the task. |
| 2 | Partially present, with a major visible or functional gap. |
| 3 | Usable on the main path, with clear consistency or coverage gaps. |
| 4 | Strong, verified for the main path; a bounded polish or validation gap remains. |
| 5 | The criterion acceptance is verified across relevant views/states with no known material gap. |

## Twenty criteria

| # | Criterion | Acceptance required for the top level |
| --- | --- | --- |
| 01 | Immediate purpose | The first glance identifies what the screen controls and how to begin. |
| 02 | Glanceable status | The current playing/downloading/paused/error condition is quickly identifiable. |
| 03 | Primary action hierarchy | Open, Play or the next necessary action is visually primary for its context. |
| 04 | Narrative task sequence | Open/select/play/queue/save steps form a coherent sequence with no unexplained jumps. |
| 05 | Data with purpose | Numbers and indicators reflect real state and help the current decision. |
| 06 | Selective accent | Signal color highlights relevant state/action without competing decoration. |
| 07 | Negative space | Groups have breathing room while related details remain near each other. |
| 08 | Monochrome structure | Hierarchy and state remain understandable without hue alone. |
| 09 | Thematic shape consistency | Existing Enochian shape roles remain consistent across functions. |
| 10 | Purposeful micro-motion | Original press/selection feedback clarifies changes without ornamental distraction. |
| 11 | Reduced-motion continuity | Reduced motion preserves the same information and completed actions. |
| 12 | Focus tells the action story | Keyboard focus and menu/modal restoration make the next action clear. |
| 13 | Context-sensitive controls | Labels and enabled states agree with the selected media/transfer. |
| 14 | Advanced capability without clutter | Advanced media, playlist and transfer options remain reachable behind clear entries. |
| 15 | Playlist story clarity | Order, current item, add/remove/reorder and save/load routes are understandable. |
| 16 | File identity | The intended filename/item/destination remains visible and unambiguous. |
| 17 | Recovery narrative | Errors explain what happened and how to retry or return. |
| 18 | Outcome feedback | Pending, completed and failed actions give timely, truthful outcomes. |
| 19 | Centralized visual language | Views reuse the same control primitives, typography and status vocabulary. |
| 20 | Real-world functional grounding | Functions and media behaviors are real and reversible rather than cinematic simulations. |

## Gate

At least **95/100 on this lens**, no criterion below 4, and the shared mandatory workflow checks must pass. Use the same frozen evidence rules as [Ryo](RUBRIC.md). These are separate scores, not an average.
