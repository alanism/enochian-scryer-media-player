# Satori grid and layout: five-level, 20-criterion evaluation

Project-specific adaptation of a supplied reference; not an official rubric, endorsement or review by the named designer.

Supplied reference: **The Satori Grid & Slide Layout Rubric.md**. SHA-256: 98f5f68c6fc2b1b8ec2b6d44e87823772c7b4746fc8f6218fe8ca1b0a14623b7.

Apply cinematic/slide advice to real desktop utility, clarity, material fidelity, hierarchy and motion. Existing user elements and usability requirements take priority over film-specific prescriptions. No fictional data or decorative motion is required for points.

## Five levels

| Points | Anchor |
| --- | --- |
| 1 | Absent or contradicts the task. |
| 2 | Partially present, with a major visible or functional gap. |
| 3 | Usable on the main path, with clear consistency or coverage gaps. |
| 4 | Strong, verified for the main path; a bounded polish or validation gap remains. |
| 5 | The criterion acceptance is verified across relevant views/states with no known material gap. |

## Twenty criteria

| # | Criterion | Acceptance required for the top level |
| --- | --- | --- |
| 01 | Spatial canvas and anchors | Primary groups align to intentional canvas axes rather than arbitrary positions. |
| 02 | Modular grid | Explicit columns or equivalent modules organize dominant and supporting groups. |
| 03 | Spacing and margin repetition | Repeated margins and gutters create consistent spatial echoes. |
| 04 | Macro/micro negative space | Major zones breathe and dense local information remains readable. |
| 05 | Typographic ramp | A documented proportional type ramp distinguishes title, label, body and data. |
| 06 | Font and weight pairing | One coherent family and meaningful weight/size differences identify roles. |
| 07 | Focal primacy | The task-relevant primary action or media object has clear primacy. |
| 08 | Eye choreography | Entry, context and action follow a predictable reading path. |
| 09 | Friction and flow zones | Extra friction is reserved for consequential choices; routine tasks flow. |
| 10 | Scale checkpoints | Real supported desktop/compact/narrow sizes are checked for disappearing detail and overflow. |
| 11 | Intention test | The screen purpose and first action can be identified quickly without instructions. |
| 12 | Cognitive relief | Calm surfaces and grouped controls prevent competing attention demands. |
| 13 | Active negative space | Spacing communicates grouping and the next action, not just decoration. |
| 14 | Temporal flow rhythm | The open/play/edit/save journey preserves context through its transitions. |
| 15 | Contrast and isolation | Important actions/status are isolated through existing contrast and scale roles. |
| 16 | Spacing harmonics | Related layout areas repeat the same spacing vocabulary. |
| 17 | Type proportionality | Type size/leading remain deliberate and legible across all supported views. |
| 18 | Aspect and platform fluency | Layouts suit an Omarchy desktop, compact window and supported browser widths. |
| 19 | Shape-role clarity | Existing circles, caps, sliders and transport glyphs consistently identify their jobs. |
| 20 | Controlled grid emphasis | The primary transport/media area gains intentional emphasis without arbitrary rotation or broken alignment. |

## Gate

At least **95/100 on this lens**, no criterion below 4, and the shared mandatory workflow checks must pass. Use the same frozen evidence rules as [Ryo](RUBRIC.md). These are separate scores, not an average.
