the installed-system check is recorded below.

       xcb_x11 as the video output; decoder supplies the first video picture.

       resumes, seeks to 7 seconds, and stops.
PASS — Volume set command accepted. Audio output was intentionally silent
       (VLC dummy audio module); audible playback/volume was not verified.
PASS — All four .vlt archives: XML DTD validation, packaged asset references,

PASS — Dial interaction uses VLC's 45°..315° bottom-origin convention, matching
       the original face's visual -135°..135° rotation.
PASS — Installer tested in an isolated XDG_DATA_HOME; resulting desktop entry
       passes desktop-file-validate. Both shell scripts pass syntax checks.

Preview PNGs are compositions of the actual packaged skin assets and exact
control positions. They illustrate the idle appearance; they are not screen
captures of video playback and contain no fabricated media collection.

Limits:
- Playback commands were exercised through VLC's local control interface.
  Every GUI button was not manually clicked, and pointer/keyboard interaction
  across all auxiliary dialogs was not exhaustively tested.
- The initial pass exercised live playback in normal skins. The later
  iteration below also exercises both compact skins.
- Audible system audio, physical media keys, suspend/resume, multiple monitors,
  high-DPI fractional scaling and hardware decoding were not verified.
- File selection, preferences, context menus and errors remain VLC Qt dialogs.
- This is a Linux Skins2/XWayland reskin, not a VLC 4 native Wayland fork.
